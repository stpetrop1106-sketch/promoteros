## A bug found and fixed, not just styled around
`app/campaigns/[id]/brief/page.tsx` was passing `t` (a function) as a prop into the `"use client"`
`BriefForm` — a straight violation of CLAUDE.md's server/client boundary rule, and it crashed
every load of `/campaigns/[id]/brief` with "Functions cannot be passed directly to Client
Components." Confirmed via `git show HEAD` that this predates my session — it is not something I
introduced. Because it is in a file I own, and it fully blocks the screen my parcel is responsible
for, I fixed it the same way three sibling client components in this very parcel already do
(`availability-link.tsx`, `cancel-assignment-button.tsx`, `mark-no-show-button.tsx`): the client
component now resolves its own `t = translatorFor(DEFAULT_LOCALE)` instead of receiving it as a
prop. No key renamed or deleted, no behaviour changed — purely a delivery-mechanism fix matching
the established pattern.

## Notes for the manager
- **`components/ui/**` untouched**, as required — everything above was composed from what already
  existed (`Section`, `DetailList`/`Detail`, `StatStrip`/`StatTile`, `Avatar`, `Icon`,
  `buttonClassName`, `Card flush`, `Table bare`). Nothing new was needed.
- The three biggest changes for "expensive, not a wireframe": (1) one raised `Card` per screen
  for the thing the screen is actually about — a promoter's identity, a shift's coverage, a
  campaign's overview — with everything else at the default depth; (2) `Card flush` + `Table
  bare` everywhere a table used to sit inside a card and draw two frames; (3) a consistent
  `PageHeader` `eyebrow` back-link with a chevron icon on every detail screen, replacing five
  different hand-rolled "back" links.
- Left deliberately rough: the coordinator-availability grid's per-day `Card` still hand-rolls its
  own selected-state colours on top of `Button secondary` (green/amber/red overrides) rather than
  reaching for a kit variant — I did not touch its interaction logic, only spacing and a few
  wrong-token text colours, since going further risked changing behaviour I was told not to touch.
  If the owner wants a real "selected chip" treatment there, it is a `components/ui` conversation,
  not mine to solve by composition.
- The campaign report's `Figure` component (units/sales/interactions totals, with the
  "incomplete" basis badge) was deliberately left as its own hand-rolled `dt`/`dd`, not folded
  into `StatTile` — `StatTile`'s `label` is a plain string and has no slot for the badge that sits
  next to it, and inventing one would have meant touching `components/ui`, which is frozen.
