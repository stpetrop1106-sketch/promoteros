# A2 — coordinator and owner workflow audit

**Status:** in_review · **Updated:** 2026-09-21 · **Deliverable:** `docs/audit/workflows.md`

Walked both sides of the product as a user on an isolated dev server (`.next-A2`, port 3308)
against the live database. No application code touched. **32 findings: 3 blockers, 12 serious,
11 annoying, 6 cosmetic**, plus a "designed this way" section and three false alarms recorded so
nobody re-chases them.

**Worst:** the Excel/CSV import writes the **wrong date on every shift** — a real Excel date cell
lands one day early (22/09 → 21/09) and a CSV additionally reads any day ≤ 12 month-first
(10/09 → 08/10). Silent, and it defeats the past-date warning. One-line fix in
`lib/import/dates.ts:98`; all 32 import tests pass with it present because their fixtures use
`Date.UTC`, which no real spreadsheet contains. Close behind: `/privacy/promoters` **500s as soon
as a second agency exists** (verified by creating one), and `SelectField`'s `hidden` placeholder
makes three write paths **silently pick the first client / store / campaign**.

Could not reach: no-show marking and the `window.confirm`-gated actions (the pane auto-dismisses
native dialogs), billing states past trialing, check-in/photo submission, and the admin console's
reason-gated view — it writes an irreversible audit row against the owner's own agency.

All test data deleted: one agency, two auth users, one client, one campaign, one store, two
sections, three shifts, three promoters and their invitations, assignments, availability and brief.
`agencies` is back to one row and `/privacy/promoters` returns 200 again.
