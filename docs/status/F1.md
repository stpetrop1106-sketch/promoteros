## Notes for the manager

- **I introduced and then caught a regression on #24.** My first attempt wrapped the invite form's
  action (`<form action={submit}>` calling `formAction(formData)` inside) to clear the stale flag
  on a new submit. That silently stopped the form submitting at all — no invitation, no error,
  nothing — which is exactly the class of bug this audit round exists to find. I only found it by
  trying to send a real invitation. The fix keeps `<form action={formAction}>` untouched and
  detects a fresh result by `useActionState` result identity instead. **I then sent a real
  invitation through the form and confirmed the row appeared.** If anyone reviews one thing in this
  parcel, make it `InviteForm` in `app/settings/team/team-controls.tsx`.
- **Something the audit missed, next door to #26.** `saveBrief` updates the existing brief row in
  place and never clears `published_at`. "Αποθήκευση πρόχειρου" on an already-published brief
  therefore republishes the edited text to every promoter immediately, while the button says
  "draft". I made the screen say so loudly (the honest fix inside my scope); making draft actually
  mean draft needs a new version row, which is a schema decision.
- **#25's second half is deliberately not done.** The audit asks for a search box *and* "a way to
  see who has already been sent one". The second needs somewhere to record it — a column, i.e. a
  migration this parcel may not write. I did not fake it in browser storage.
- **`{count}` plurals I did not sweep.** Two more are wrong in the same way as #18 but live in
  files owned by the lane fixing findings 3, 8 and 17, so I left them:
  `campaigns.list.shift_count` (`app/campaigns/page.tsx:116`) and
  `campaigns.shifts_new.preview_count` (`shift-series-form.tsx:332`). A third is in a file I do
  own but is a whole-sentence notice rather than a count phrase, so it needs a wording decision
  rather than a plural split: `billing.notice.trial_ending.body` renders «Απομένουν 1 ημέρες
  δοκιμής» on the last day of a trial.
- **Collision risk.** Finding 17 also lands in `app/campaigns/[id]/page.tsx` (line ~240,
  `{shift.on_date}`) and in `app/campaigns/_shared.ts`. I edited the foot of that same page for
  #12. Different region, but worth a careful merge.
- **`components/ui` contract.** `ConfirmButton` is a new file plus one new export block at the
