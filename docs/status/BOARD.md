## Incidents

**I1 — the project was not its own git repository.** Resolved: `git init`, and the working copy moved
out of OneDrive to `C:\dev\promoteros`, where `.next` is no longer locked by the sync client.

**I2 — migration `0004` was written but never applied**, so the public waitlist form failed for every
visitor. Resolved. The registry above now tracks *applied*, not *written*.

**I3 — five agents killed at once by the session limit.** No work was corrupted, because a killed
parcel leaves a build that does not compile rather than one that silently misbehaves — the i18n type
contract turned two of those into loud failures. **Concurrency was reduced to two agents**, which
proved strictly faster to a finished parcel.

**I4 — an applied migration was corrupted in the working copy** (`revoke_agenc+y_invitation`).
Caught by an agent reading it, restored from git. Nothing had been re-run against the database.
